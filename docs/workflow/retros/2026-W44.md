## What went wrong / friction

1. **Plan self-contradiction on the red-flag semantics (DEVIATION 1)**: WI-018 plan step 3 pre-registered "wall = red flag, not a win" while step 4 said "invoke G3 only for G2 survivors". Build resolved it fail-closed (`g3_eligible = g2_pass and not red_flag`) and flagged it — correct call, but a Build agent made a gate-interpretation decision that belongs to the human. **Lesson:** when two plan steps conflict, the pre-registered failure mode should mechanically gate downstream steps; no agent should have to pick.
2. **Significance bars don't scale with N (the WI-018 core lesson)**: over 2,850 held-out dates the OOF CI half-width shrinks to ~0.006–0.009, so almost any nonzero cross-sectional rate difference is "significant". 2,506 of 3,658 hypotheses passed all three bars. The probe has power; the *gate* has none at this N. More data made the test worse, not better.
3. **Best-window selection bias one layer up**: two G1 families (`fib_dist`, `range_pos`) failed the representativeness check — their atlas evidence is single-window, i.e. mild survivorship inside the WI-017 feature-prune step.
4. **G3 cost proxy unvalidated**: the skip path means the `|IC|×1000` bps overlay was exercised only on synthetic survivors; 20+5 bps remain assumptions. Every "nothing survives costs" verdict (WI-011, any future G3) rests on an unvalidated proxy.
5. **WI-016 label cols embedded in metadata panels** (leakage footgun) — fixed forward in WI-013 scope but worth remembering as a class.

## Lessons → rules proposed

- **Effect-size over significance**: any future G2-style probe must carry an effect-size floor (lift ≥ cost-aware bps minimum) and fold-wise sign stability alongside CI/BH bars. Significance alone is evidence-free at this panel size. (Details: `docs/workflow/designs/D-019-g-gate-recalibration.md`.)
- **Fail closed on ambiguity**: pre-registered failure modes gate downstream plan steps automatically; plan text should never leave two steps contradicting each other.
- **Representativeness is a gate input, not a caveat**: families failing the check get tagged in the artifact; any WI citing them must re-test the family's other windows first.
- **Validate the cost proxy** against realized fills from the WI-016 paper-track before trusting any future G3 cost verdict; confirm the 20+5 bps figures against the actual IBKR schedule.
