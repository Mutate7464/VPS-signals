## 1. Objective and invariant
Build the eval machinery the 7 built Track B families are missing (nr_flags, clv, cusum_flag, stoch_rsi, connors_rsi, fail_count, swing_levels — all built under `data/features/l0_ext/`, none evaluated). One driver, `--family <f>`, runs a delta-vs-baseline event-level grid per family: baseline = the incumbent event panel WITHOUT any tested family's columns; arm = baseline + that family's features joined at each event's detection bar. Delta = fold-paired OOF AUC (binary b_hold) / rank-IC (xsec continuous) — mirror `scripts/run_l0_r12.py`'s panel/label/stat machinery read-only (249-col panel via `ext.build_variant_panel`, `cell_cv` machinery). Per-family BH-FDR (alpha 0.05) over m = targets × learners × markets; survivors = positive-delta FDR-passing cells; decision statistic cross-market min delta (PROVISIONAL until admin ratification).
- Invariants: n_jobs=2, float32, symbol-sequential / pyarrow reads, no all-ticker uncompressed frame. Predictive-only license (D-023): no trading/economic metrics. Prereg: this card is the prereg for each family's own BH-FDR family (7 jobs, one per --family).
