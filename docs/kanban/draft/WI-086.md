## 1. Objective and invariant
Build join index (features ⋈ oof ⋈ targets on (symbol,date) per market, cached with (path,size,mtime) fingerprint), global filter bar (sliders on whitelisted features, date range, target selector over legacy y_*/p_*/y_20d_stay), KPI strip (trades/yr, hit rate, lift, EV, profit factor) with the watermark.
- Invariants: reads only via column-projected pyarrow; float32; n_jobs=2; UI server writes ONLY under `state/viz/`; data files opened read-only; no `dcc.Interval`; `debug=False`; 1 gunicorn worker.

## 2. I/O contract and blueprint (literal)
- Read: joined panel via loader.
- Write: state/viz/join_{MKT}.parquet cache + fingerprint in state/viz/manifest.json.
- Filter spec in one dcc.Store serialized to URL query string.
- EV horizon matched to target (15 for y_15d_*, 20 for y_20d_*); sign convention for low/down targets = OPEN QUESTION, implement behind a config flag and flag in UI.

## 3. Definition of Done (binary)
- [ ] KPIs match hand-computed pandas reference on one market+target to 1e-6.
- [ ] Watermark renders on every KPI.
- [ ] p95 filter round-trip ≤1 s over tunnel (measured, recorded in bench.json).
