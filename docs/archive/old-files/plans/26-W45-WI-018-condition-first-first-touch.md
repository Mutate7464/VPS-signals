# WI-018 — Condition-first directional study: first_touch @ w≈34 (USD)

## GOAL
Deliver a USD-only condition atlas and a falsification-first memo for `first_touch_34`; run the cost overlay only if the pre-registered G2 probe passes.

## CONSTRAINTS
- Follow accepted ADR `docs/workflow/designs/D-018-condition-first-first-touch.md`: G1 atlas → G2 probe → conditional G3 cost overlay; both quintile and tercile binnings; USD only (CAD skipped); conjunction depth ≤2; BH-FDR 5%; memo-only ship shape.
- Use existing on-disk WI-017 derived targets and features plus exactly the 88 `keep_columns` in `reports/wi017/run5_prune_recs.json`. `first_touch_34` is primary; 24/39 are secondary robustness reads only. Validate target-family representativeness for `atr_pct`, `fib_dist`, and `range_pos` before including those families.
- Reuse `src.wi011.stats.fold_blocks` for five chronological folds and `max(20, horizon)` embargo; `src.wi016.probe.benjamini_hochberg` for BH-FDR; `src.perfanalytics.correlation.alignment.block_bootstrap_margin` for circular 20-date bootstrap margins (1,000 draws, seed 42); and `src.wi016.probe.cost_overlay` for its screening proxy. Do not reimplement these helpers. Same-sign bar applies.
- Run sequentially by symbol; do not materialize an all-ticker uncompressed frame. Cast calculated feature DataFrames to `float32` immediately. `n_jobs<=2` (prefer sequential); bounded memory; no secrets; no live trading or order execution. Preserve frozen WI-014/016 artifacts.
- Writes are limited to `src/wi018/`, `reports/wi018/`, `docs/`, and `tests/`. No CAD work, trading integration, or shortlist CSV. G3 uses the WI-011 20+5 bps assumptions, labeled assumptions; a G2 failure means G3 is skipped and the memo records NO-GO.

## STEPS

1. **Preflight the inputs before any study implementation/run.** Add `src/wi018/data_probe.py` to inspect `reports/wi017/derived/<SYM>.parquet`, `reports/wi017/features/<SYM>.parquet`, and `run5_prune_recs.json` sequentially. Assert matching sets of 593 USD symbols; nonempty inputs; per-symbol feature/target date and row alignment; presence of `date`, `first_touch_34`, secondary targets `first_touch_24`/`first_touch_39`, and all 88 keep columns; feature schema has 264 columns; report per-symbol and total row counts, date bounds, null/finite counts, and target values without assuming undocumented encodings. Add `tests/test_wi018_data_probe.py` for schema/count/alignment and malformed-input cases. **Acceptance:** input probe passes on disk and emits `reports/wi018/preflight_USD.json` with observed row counts; no study outputs are produced before this passes. **Verify:** `uv run python -m src.wi018.data_probe --market USD --assert-inputs` and `uv run pytest tests/test_wi018_data_probe.py -q`.

2. **Build the guaranteed G1 atlas.** Add `src/wi018/atlas.py` and tests `tests/test_wi018_atlas.py`. Stream symbols from verified inputs; for each feature form both tercile and quintile states using within-date USD cross-sectional quantiles (exclude undefined feature values; record empty/undersized groups). Report conditional up-first/down-first/neither rates for `first_touch_34` against the unconditional split. Use `block_bootstrap_margin` on the per-date rate series to report 95% margins/CIs (20-date blocks, 1,000 draws, seed 42). Emit `reports/wi018/atlas_USD.json` and `.md`. **Acceptance:** every feature/binning is represented or explicitly marked unevaluable; estimable rates are finite and sum to 1 within tolerance; CIs are present; the three flagged feature families receive an explicit target-representativeness check. **Verify:** `uv run pytest tests/test_wi018_atlas.py -q` and `uv run python -m src.wi018.atlas --market USD --check-report reports/wi018/atlas_USD.json`.

3. **Run G2 only after G1 passes.** Add `src/wi018/probe.py` and `tests/test_wi018_probe.py`. Use atlas states to test univariate conditions first; apply `src.wi016.probe.benjamini_hochberg` at 0.05 across the complete G2 hypothesis family (both binnings and directions). Generate conjunctions only from univariate FDR survivors, cap depth at two, and include those hypotheses in the same correction family. Evaluate held-out lift versus the unconditional 38/30/33 split over five chronological folds from `fold_blocks`, using embargo `max(20,w)`; use `block_bootstrap_margin` on per-date lift series and apply the same-sign clause. Use `first_touch_34` for decisions; report 24/39 only as robustness reads, never as alternate selection targets. **G2 pass:** at least one condition has an out-of-fold lift whose CI excludes zero, passes BH-FDR 5%, and clears the same-sign bar. Report hypothesis counts, fold/embargo details, and survivor density; a wall of survivors is flagged as a red flag, not a win. Emit `reports/wi018/probe_USD.json` and `.md`. **Acceptance:** deterministic reruns agree; no condition passes unless all stated criteria hold; failure cleanly marks G3 skipped. **Verify:** `uv run pytest tests/test_wi018_probe.py -q` and `uv run python -m src.wi018.probe --market USD --check-report reports/wi018/probe_USD.json`.

4. **Run G3 conditionally and produce the memo-only decision artifact.** Add `src/wi018/cost_overlay.py` and `tests/test_wi018_cost_overlay.py`. Invoke only for G2 survivors; call `src.wi016.probe.cost_overlay` at 25 bps total (WI-011 20+5 assumptions), explicitly label its IC-to-bps result as a screening proxy, not a P&L model; default to NO_TRADE when net edge is nonpositive or not estimable. Emit no executable rules or shortlist CSV. If G2 fails, record G3 as skipped. Write `reports/wi018/summary_USD.md` with G1 deliverable, G2 verdict, any G3 outcome, limitations, and whether follow-up is warranted. **Acceptance:** cost math and branch behavior have regression tests; memo states the final verdict and explicitly says no trading integration/shortlist is shipped. **Verify:** `uv run pytest tests/test_wi018_cost_overlay.py -q` and `grep -E 'G1|G2|G3|NO_TRADE|assumption|memo' reports/wi018/summary_USD.md`.

5. **Final integrity and regression verification.** Ensure report schemas/counts and gates agree across preflight, atlas, probe, and memo; keep generated artifacts under `reports/wi018/`; add any cross-artifact assertions to `tests/test_wi018_reports.py`. **Acceptance:** all WI-018 tests and the repository suite pass; every report records USD-only scope, input provenance, and deterministic configuration; no frozen artifact changed. **Verify:** `uv run pytest tests/test_wi018_*.py -q` and `uv run pytest`.
