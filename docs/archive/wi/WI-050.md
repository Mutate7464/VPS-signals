- Output: new module `src/swing_bsh/precision_diag.py`, no file writes, exposing:
  - `precision_at_k(y, p, ks=(10,25,50,100)) -> dict[int,float]` — fraction of positives in the top-k scores (k counts rows, ranked desc by `p`).
